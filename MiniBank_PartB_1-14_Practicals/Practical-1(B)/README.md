# Practical 01 – MiniBank

## Objective

To create the initial structure of a console-based banking application using Java records, enums, Scanner, loops, and switch expressions.

## Application Details

MiniBank is a simple console application developed as the starting point of a semester-long banking project.

## Concepts Used

- Java Records
- Enumerations (Enum)
- Scanner class
- Switch expressions
- While loop
- Conditional statements
- Exception handling

## Implemented Features

1. Displays bank information using the BankInfo record.
2. Provides a numbered banking menu.
3. Uses MenuOption enum for available operations.
4. Accepts menu choices from the user.
5. Displays placeholder messages for banking operations.
6. Repeats the menu until the user selects Exit.
7. Handles invalid input.

## How to Run

Compile:

```bash
javac MiniBank.java
```

Execute:

```bash
java MiniBank
```
