# Practical 14 — Part A

These are independent example implementations aligned to the topics in the supplied CEUE203 practical list.

## Compile and run
Open a terminal in this folder, then run:

```bash
javac *.java
java ClassName
```

Replace `ClassName` with the public class you want to run (without `.java`). Some examples accept optional command-line arguments.

`LayeredAppTests.java` is a lightweight manual test harness and does not require JUnit. The practical list's JUnit exercise still requires adding JUnit 5 to the project if formal JUnit tests are required.
