# MiniBank | Java-Based Banking Application

A console-based banking application developed as part of the Object-Oriented Programming laboratory. The project focuses on applying Java programming concepts through the gradual development of a banking system over 14 practical sessions.

---

## About the Project

**MiniBank** is an academic Java project designed to demonstrate how fundamental programming concepts can be used to develop a simple banking application.

The application is being developed step by step throughout the semester. Each practical introduces new programming concepts and extends the existing application with additional functionality.

The main objective is to build a structured, menu-driven application while understanding object-oriented programming, data management, and Java application development.

## Application Modules

The repository contains two major sections.

### 1. Part A — Java Practice Programs

Contains the individual programming exercises assigned in Practical 1 to Practical 14.

Each practical is maintained separately to make the source code easy to locate, compile, and evaluate.

### 2. Part B — MiniBank Project

Contains the continuous development of the MiniBank application.

The project begins with a basic interactive menu and will be extended according to the requirements of each practical.

Planned banking operations and supporting programming concepts will be introduced progressively as specified in the laboratory manual.

## Initial Application

The first version of MiniBank establishes the basic application structure.

Initial components include:

- `BankInfo` — stores the bank name and branch information.
- `MenuOption` — defines the available banking operations.
- `MiniBank` — contains the main application logic.
- Interactive menu — accepts the user's selection.
- Switch expression — processes the selected menu option.
- Exit operation — terminates the application properly.

The initial menu includes:

| Option | Operation |
|---|---|
| 1 | Open Account |
| 2 | Deposit |
| 3 | Withdraw |
| 4 | Transfer |
| 5 | Exit |

Additional functionality will be added in subsequent practicals.

## Setup and Execution

### Prerequisites

1. Install JDK 17 or a compatible newer version.
2. Install a Java-supported IDE or use a terminal.
3. Clone the repository.

### Check Java Installation

```bash
java -version
javac -version
```

### Clone Repository

```bash
git clone https://github.com/YOUR-USERNAME/oop-minibank-25IT061.git
```

### Run MiniBank

Navigate to the directory containing `MiniBank.java` and execute:

```bash
javac MiniBank.java
java MiniBank
```

If the source file is inside a package or a different directory, use the corresponding compilation path.
